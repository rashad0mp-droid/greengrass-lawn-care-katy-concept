# GreenGrass Lawn Care: concept website

Concept preview of a one-page website for GreenGrass Lawn Care, Tree Services & Landscaping (Katy, TX). It is **not** the official business website. The page carries a `noindex` tag so search engines won't index it.

- `index.html`: the whole site (inline CSS and JS, no build step)
- `images/`: stock photos from Unsplash (free under the Unsplash License). These are placeholders to replace with the business's own job photos before launch.

Items marked **CONFIRM WITH CLIENT** (prices, hours, insurance, payment policy, full service area) need the owner's input. The forms show a thank-you message but don't send anything until a handler such as Formspree or Netlify Forms is connected.
